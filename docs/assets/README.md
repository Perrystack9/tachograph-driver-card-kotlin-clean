# Project graphics

Original SVG artwork for the Driver Card Parser & Android USB Library.
License and origin notices: [LICENSE](../../LICENSE) and [NOTICE](../../NOTICE).

| Asset | Purpose |
| --- | --- |
| `logo.svg` | Articulated truck with RN3 lettering on its trailer and a highway lane |
| `banner.svg` | Night-highway scene with an original generic truck and plain RN3 trailer lettering |
| `modules.svg` | Application, USB transport and core dependency boundaries |
| `platforms.svg` | Static toolchain/platform/project-license labels; no CI status claim |

Palette: midnight navy `#0c1726`, slate `#1b3043`, warm amber `#ffad66`,
light text `#f5f2e9`. The transport identity uses an original generic truck, abstract
road lines and simple trailer lettering; no manufacturer or real vehicle is depicted.
All assets are self-contained SVGs with titles/accessible descriptions or labels,
no scripts, external resources, embedded fonts or third-party marks. Text uses
system font fallbacks. Keep a clear margin around the logo and use the original
viewBox when resizing. No affiliation with a tachograph vendor or certification
body is implied. These assets do not depict a real driver card or its data.
